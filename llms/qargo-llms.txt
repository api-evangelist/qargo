# Qargo TMS API

> Qargo is an intelligent transport management platform (TMS) for carriers, freight forwarders and 3PLs. The Qargo TMS API (OpenAPI 3.1, v1.2.0, base https://api.qargo.com) exposes tenant-level integration and operational endpoints across orders, trips, accounting, companies, resources, documents and tasks, plus inbound and outbound webhooks. Service-to-service auth is OAuth2 client-credentials (JWT); webhooks use HTTP Basic.

## APIs
- [Qargo TMS API (Tenant)](https://api-docs.qargo.com/docs): main integration + operational API — 84 paths, 114 operations
- [Subcontractor API](https://api-docs.qargo.com/subcontractor/docs): fleet dispatch and subcontractor endpoints
- [Customer API](https://api-docs.qargo.com/customer/docs): customer portal, order tracking and status
